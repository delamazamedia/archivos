Aumentar la captación de pacientes online mediante dos líneas de trabajo paralelas:

   que están frenando que los visitantes agenden una sesión.

   relevantes de psicología online en Chile, usando el pipeline de skills:
   `brand-voice-capture` → `seo-keyword-research` → `topic-cluster-architect` →
   `seo-article-writer` → `wordpress-seo-publisher`.
